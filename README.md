O Rotas é uma aplicação web desenvolvida em Python, com interface construída utilizando Gradio, voltada ao gerenciamento e à visualização de rotas para entregadores motociclistas.

O sistema permite selecionar entregas cadastradas, visualizar trajetos em mapas interativos e consultar informações como distância, tempo estimado e instruções de navegação.

Funcionalidades

- Listagem e seleção de entregas.
- Cálculo de rotas utilizando a API OSRM.
- Visualização de mapas interativos com Folium.
- Exibição de distância e tempo estimado do percurso.
- Instruções de navegação em português.
- Interface web desenvolvida com Gradio.

Tecnologias utilizadas

- Python — Linguagem principal.
- Gradio — Interface web.
- Folium — Geração de mapas interativos.
- Requests — Comunicação com a API.
- OSRM — Cálculo de rotas.
- OpenStreetMap — Dados cartográficos.
